# Proyecto Web: Malibú Club Café de Playa

Sitio web responsivo y semántico estructurado en HTML5, CSS3 y JS.

- `index.html`: Página principal.
- `css/`: Hojas de estilo generales y responsivas.
- `js/`: Scripts de interacción y validación.
- `img/`: Recursos de imágenes organizados por categoría.
- `pages/`: Páginas secundarias del sitio.
